SQL Proof of Work

Example: Rank high-defect products by month

Demonstrates CTEs, aggregation, defensive division, and a window function—the kind of SQL used in recurring operational analysis.

WITH monthly_quality AS (
    SELECT
        product_id,
        DATE_TRUNC('month', production_date) AS month,
        SUM(units_produced) AS units_produced,
        SUM(defect_units) AS defect_units
    FROM production_quality
    GROUP BY 1, 2
), ranked AS (
    SELECT *,
        defect_units * 1.0 / NULLIF(units_produced, 0) AS defect_rate,
        DENSE_RANK() OVER (
            PARTITION BY month
            ORDER BY defect_units * 1.0 / NULLIF(units_produced, 0) DESC
        ) AS defect_rank
    FROM monthly_quality
)
SELECT *
FROM ranked
WHERE defect_rank <= 5
ORDER BY month DESC, defect_rank;

Note: This portfolio case study uses a synthetic data model and illustrative business questions. It is designed to demonstrate analytical workflow without exposing employer-confidential data.
